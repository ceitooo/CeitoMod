# CeitoMod

Suite de gestión de mapas personalizados, complementos visuales y herramientas de cliente.

## Características

- **Gestor de Mapas:** Descarga, instalación y organización de mapas de práctica y arenas personalizadas.
- **Visualizador de Perfil y HUD:** Overlay local personalizable con avatares (soporte para imágenes estáticas y animadas), títulos y seguimiento de estadísticas.
- **Tienda de Texturas:** Navegación por pestañas y paginación para calcomanías y complementos visuales.
- **Rendimiento:** Ejecutable optimizado en Rust y WebView2 con bajo consumo de memoria y cierre limpio de procesos.

## Descarga e Instalación

1. Descarga el ejecutable desde la sección de **Releases**.
2. Ejecuta `CeitoMod.exe` directamente en Windows 10 u 11.
3. Las actualizaciones futuras se gestionan automáticamente al iniciar la aplicación.
